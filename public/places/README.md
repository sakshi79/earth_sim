# Pre-built featured places

Generated by `npm run build-places` (scripts/build-places.mjs). One folder per featured place:

- `place.json`: the terrain window (zoom, tiles, top-left tile) and credits.
- `terrain.png`: elevation for the window, Terrarium-encoded (metres = R·256 + G + B/256 − 32768),
  from AWS Terrain Tiles (SRTM, GMTED, ETOPO1 and other sources).
- `imagery.jpg`: satellite imagery for the window.
