# Player model

`player.glb` is the mannequin from the **Universal Animation Library** (Standard) by Quaternius,
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
([source](https://opengameart.org/content/universal-animation-library)).

It is trimmed to the 11 animations the game uses and meshopt-compressed by
`npm run build-player-model -- <AnimationLibrary_Godot_Standard.glb>` (scripts/build-player-model.mjs).
